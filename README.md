# data09-16 · 하네스 도면 자재 판별·BOM 자동 산출 에이전트

## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-16/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

**1차 목표 — 도면 자재 판별**

1. **마스터 데이터** — 부품 매핑 마스터(통합 자재 마스터: 부품 분류·사내 자재 코드·제조사 품번·고객사·고객사 품번)를 올리고 실제 열 이름을 표준 항목에 연결합니다. 연결은 브라우저에 저장되어 같은 양식 파일은 다음부터 자동으로 연결됩니다.
2. **도면 자재 판별** — 도면 PDF 또는 이미지를 올립니다.
   - 글자가 살아 있는 PDF 는 품번 후보를 좌표와 함께 자동으로 찾아 도면 위에 표시합니다. 스캔본·이미지는 「위치 표시」로 도면 위를 누르거나 끌어 표시하고, 품번은 표에 입력하거나 목록을 「배치 대기열」에 붙여 넣어 차례로 넣습니다.
   - 각 자재가 **기존 — 제조사 품번(초록 실선) · 고객사 품번(노랑 굵은 실선, 매핑 없으면 노랑 점선) · 확인 필요(보라 점선) · 신규(빨강 겹선+빗금) · 품번 미입력(회색 점선)** 으로 표시됩니다(v0.3 수강생 답: 노랑 = 도면에 제조사 품번이 아닌 고객사 품번이 적힌 경우). 확인 필요는 후보를 고르거나 신규로 확정합니다.
   - **고객사별 학습 규칙** — 「규칙 가르치기」로 도면 글자를 눌러 「제조사 품번 예·고객사 품번 예·고객사 알아보기 글자·품번 아님」을 알려 주면 품번 모양(정규식)·표제란 글자·제외 목록이 고객사별로 쌓이고, 같은 고객사 PDF 를 올리면 저절로 적용됩니다. 고객사 대조표(고객사 품번 → 제조사 품번)·부품표 열 연결도 규칙에 저장되며 JSON 으로 내보내·가져올 수 있습니다. 기계학습이 아니라 예시로 만드는 규칙이고, 진짜 AI 학습은 2단계입니다.
   - **도면 부품표** — 부품표형 고객사는 PDF 의 부품표에서 머리글·열 위치를 읽어 행마다 품번·수량을 뽑습니다(「표 영역 지정」으로 표를 끌어 감쌀 수도 있음).
   - **커넥터 부자재** — 1번 화면에 커넥터 부자재 마스터를 올리면 커넥터마다 터미널·실 등 부자재가 보이고 「부자재 포함 자재 목록」(엑셀 시트)에 펼쳐집니다.
   - 표의 행을 누르면 도면의 그 위치로, 도면의 표시를 누르면 표의 그 행으로 갑니다.
   - **산출물 1** 표시된 도면 PNG, **산출물 2** 자재 판별 엑셀(자재 판별 · 품번별 요약 · 확인 필요 · 도면 정보)·CSV 를 내보냅니다. 첫 시트는 자재 종류 | 도면 표기 품번 | 매핑된 사내 자재 코드 | 신규 여부 순서에 쪽·좌표가 붙습니다.

처음이라면 2번 화면의 **「예시 A: 라벨형 PDF」·「예시 B: 부품표형 PDF」** 를 눌러 보세요(예시 고객사 규칙 2개와 커넥터 부자재 마스터가 함께 들어가 규칙 자동 적용을 볼 수 있습니다). 예시 A 는 가상의 통합 자재 마스터 11행과 품번이 15곳에 적힌 도면 1쪽이 들어갑니다(하이픈 빠진 품번, 두 조각으로 찍힌 품번, 제조사 품번 표기, 후보 2개, 사내 코드 빈칸, 다른 고객사 품번, 0 자리에 영문 O, 마스터에 없는 품번, 품번처럼 생긴 도면 번호, 전선 규격·치수를 일부러 넣음). **「예시 A: 스캔 이미지로」** 는 같은 도면을 글자 없는 그림으로 불러와 위치 표시 흐름을 연습합니다.

**다음 단계 — BOM 산출(메뉴 B1~B3, v0.1 1차 범위)**

- **B1 부품 LIST** — 커넥터(위치·품번·극수)와 회로(위치·극 번호·전선 규격)를 입력하거나 붙여 넣습니다.
- **B2 검증·산출** — 품번 교차 검증과 Application Spec 기반 터미널·실 산출, 확인 대상 처리
- **B3 BOM** — 사내 자재 코드 기준 BOM 엑셀(BOM · 확인 대상 · 회로별 산출 근거)·CSV
- 1번 화면의 「BOM 산출 예시 불러오기」로 이 흐름의 예시를 볼 수 있습니다.

- 파일은 이 브라우저 안에서만 읽고 계산합니다. 입력은 이 브라우저(localStorage)에만 저장되며, 결과 보관은 BOM 엑셀로 합니다.
- 도면 파일은 저장하지 않습니다. 새로고침 뒤에는 같은 도면을 다시 올리면 저장된 표시·처리를 그대로 이어 씁니다.
- 예시 파일(모두 가상 자료): `samples/예시도면_하네스_가상.pdf`, `samples/예시도면_부품표형_가상.pdf`, `samples/예시데이터_커넥터부자재마스터.xlsx`, `samples/예시데이터_고객사대조표_B.xlsx`, `samples/예시데이터_고객사규칙.json`, `samples/예시데이터_통합자재마스터.xlsx`, `samples/예시데이터_부품매핑마스터.xlsx`, `samples/예시데이터_ApplicationSpec.xlsx`, `samples/예시데이터_부품LIST_커넥터.csv`, `samples/예시데이터_부품LIST_회로.csv`
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음 — 도면 테스트는 `vendor/pdfjs` 로 예시 PDF 를 실제로 읽습니다)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`, 예시 도면 PDF: `node scripts/make-sample-drawing.js`
- 라이브러리: SheetJS 0.18.5(`vendor/xlsx.full.min.js`), pdf.js 3.11.174(`vendor/pdfjs/`, Apache 2.0)
