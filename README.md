## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-16/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

쓰는 순서는 화면 위 메뉴 순서와 같습니다.

1. **마스터 데이터** — 부품 매핑 마스터·Application Spec 엑셀(또는 CSV)을 올리고, 실제 열 이름을 표준 항목에 연결합니다. 연결은 브라우저에 저장되어 같은 양식 파일은 다음부터 자동으로 연결됩니다.
2. **부품 LIST** — 도면에서 읽은 커넥터(위치·품번·극수)와 회로(위치·극 번호·전선 규격)를 입력하거나 엑셀에서 복사해 붙여 넣습니다.
3. **검증·산출** — 품번 교차 검증과 터미널·실 산출 결과를 보고, 확인 대상은 후보 중 고르거나 직접 입력합니다.
4. **BOM** — 사내 자재 코드 기준 BOM 을 엑셀(BOM · 확인 대상 · 회로별 산출 근거 3개 시트) 또는 CSV 로 내보냅니다.

처음 열면 데이터가 비어 있습니다. **「예시 데이터 불러오기」** 를 누르면 가상의 마스터·도면이 들어가고, 화면 위에 「예시 데이터」 안내 띠가 표시됩니다. 예시에는 하이픈이 빠진 품번, 후보가 두 개인 커넥터, 매핑에 없는 품번, 터미널 후보 두 개, 사내 코드가 두 개인 실, 범위 밖 전선 규격을 일부러 넣어 두었습니다.

- 파일은 이 브라우저 안에서만 읽고 계산합니다. 입력은 이 브라우저(localStorage)에만 저장되며, 결과 보관은 BOM 엑셀로 합니다.
- 예시 파일(모두 가상 자료): `samples/예시데이터_부품매핑마스터.xlsx`, `samples/예시데이터_ApplicationSpec.xlsx`, `samples/예시데이터_부품LIST_커넥터.csv`, `samples/예시데이터_부품LIST_회로.csv`
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`

## 1단계 구현 범위

기획서 5장 기능 목록 기준입니다. 완료 = 이번 1단계 웹 도구에 들어감, 다음 단계 = 기획서 8장 2·3단계.

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 마스터 엑셀 가져오기 | 완료 | xlsx·xls·csv(UTF-8·EUC-KR), 시트 선택, 머리행 자동 찾기(제목 행 건너뜀), 열 이름을 표준 항목에 연결하는 화면과 미리보기, 필수 항목 확인, 연결 설정 저장·재사용. Application Spec 은 하한·상한 두 칸 또는 「0.3~0.5」 한 칸, 한 칸에 여러 품번(쉼표·세미콜론·줄바꿈) 모두 읽음 |
| 부품 LIST 입력 | 완료 | 도면 정보(도면 번호·도면명·REV·고객사·신규/설변), 커넥터 표·회로(극별 전선) 표 직접 입력, 엑셀 복사 붙여넣기(덧붙이기·바꾸기) |
| 품번 교차 검증 | 완료 | 고객사 품번 → 제조사 품번 → 사내 코드 순서로 조회, 그대로 비교 후 없으면 공백·하이픈·대소문자 정리해 비교(「표기 차이 매칭」 표시), 고객사 열이 있으면 해당 고객사 행만 |
| 종속 자재 산출 | 완료 | 커넥터 제조사 품번 + 전선 규격(+전선 종류)으로 Application Spec 조회해 터미널·와이어 실 산출, 산출 자재도 매핑 마스터로 사내 코드 부여. 수량은 회로(극) 1개당 1개(가정), 여유율은 설정 |
| 확인 대상 표시 | 완료 | 매핑 없음 · 제조사 후보 여러 개 · 사내 코드 중복 · 사내 코드 빈칸 · App Spec 에 커넥터 없음 · 규격 범위 밖 · 규격 숫자 아님 · 터미널/실 후보 여러 개 · 경계값(설정 시) · 극수 초과·극 번호 중복·없는 위치의 회로. 후보 선택 또는 직접 입력, 미해결이 있으면 내보내기 전 경고 |
| BOM 엑셀 내보내기 | 완료 | 같은 사내 코드끼리 수량 합산, 구분·사내 코드·제조사 품번·품명·수량·사용 위치·확인 상태·근거(App Spec·매핑 몇 행) 열, 확인 대상·회로별 근거 시트 포함. 실제 BOM 양식 열 순서는 양식을 받은 뒤 맞춤 |
| 방수전 산출 | 일부(설정) | 설정에서 켜면 빈 극 수(극수 − 회로 수)만큼 App Spec 의 방수전 산출. 기준 확인 전이라 기본은 꺼짐(기획서 10장 6번) |
| 설변 BOM 비교 | 다음 단계 | 2단계 — 지금은 BOM 구분(신규/설변) 표기만 |
| 도면 PDF 부품 추출 | 다음 단계 | 2단계 1순위 — 도면 샘플과 외부 AI 사용 가능 여부 확인 후 |
| 챗봇형 질의 | 다음 단계 | 3단계 |
