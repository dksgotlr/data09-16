## 결정과 이유

- **열 이름을 코드에 박지 않고 열 연결 화면을 두었습니다.** 두 마스터 엑셀의 실제 열 구성을 아직 받지 못했기 때문입니다. 열 이름으로 짐작해 미리 골라 두고, 사람이 고친 연결은 열 이름 기준으로 저장해 같은 양식 파일에 다시 씁니다.
- **품번은 먼저 적힌 그대로 비교하고, 없을 때만 정리(공백·하이픈·대소문자)해서 비교합니다.** 정리해서 맞은 경우는 「표기 차이 매칭」으로 따로 표시합니다. 품번 한 글자 차이가 다른 자재일 수도 있어 담당자가 눈으로 볼 수 있게 하려는 것입니다. 점·밑줄·슬래시 무시는 기본으로 꺼 두었습니다.
- **도면 품번은 고객사 품번 → 제조사 품번 → 사내 코드 순서로 찾습니다.** 도면에 제조사 품번이 바로 적힌 경우도 찾기 위함입니다. App Spec 에서 나온 터미널·실 품번은 제조사 품번이라 제조사 열부터 찾습니다.
- **자동으로 정할 수 없는 것은 정하지 않습니다.** 후보가 여럿이면 확인 대상으로 두고 담당자가 고르거나 직접 입력합니다(기획서 2.2). 미확정 행도 BOM 에서 빼지 않고 「확인 필요」로 남겨, 조용히 빠지는 자재가 없게 했습니다. 내보내기 전에 미해결 건수를 경고합니다.
- **커넥터 품번이 확정되기 전에는 그 커넥터의 터미널·실을 산출하지 않습니다(산출 보류).** 후보 커넥터마다 적용 터미널이 다를 수 있기 때문입니다.
- **담당자 선택은 품번·위치 단위로 기억합니다.** 같은 실 품번이 여러 커넥터에 쓰여도 사내 코드 선택은 한 번만 하면 됩니다.
- **BOM 은 같은 사내 코드끼리 합치고, 근거 열에 위치별로 어느 App Spec 행·매핑 행에서 왔는지 남깁니다**(기획서 9장 「판단 근거 기록」).
- **여유율·경계값 처리·방수전 산출은 설정값입니다.** 사내 규칙이 확인되지 않아(기획서 10장 5·6번) 코드에 고정하지 않았습니다. 기본값은 여유율 0%, 경계값 포함, 방수전 꺼짐입니다.
- **스크립트를 ES module 이 아닌 일반 스크립트로** 불러옵니다. `index.html` 을 파일로 열면(file://) 브라우저가 module 스크립트를 막기 때문입니다. `logic.js` 는 Node 테스트에서도 같은 파일을 씁니다.
- 용어는 같은 과정의 하네스 프로젝트(data09-07)와 맞췄습니다(품번·품명·커넥터·회로·신규/설변). 코드는 공유하지 않았습니다.

## 가정

- 부품 LIST 의 회로 표는 「한 행 = 커넥터 한 극에 꽂히는 전선 한 가닥」으로 보고, 행마다 터미널 1개·실 1개로 셉니다(기획서 5장 「회로(사용 극) 수 기준」). 극 번호를 비워 두면 행 하나를 한 극으로 셉니다.
- Application Spec 은 「한 행 = 커넥터 하나와 전선 규격 범위 하나에 쓰는 터미널·실(·방수전)」로 보았습니다. 한 칸에 여러 품번이 있으면 나눠 읽고, 규격 범위 칸이 둘 다 비어 있으면 모든 규격에 적용되는 것으로 봅니다(불러올 때 안내).
- 실 칸이 비어 있으면 「실 없음」(비방수 커넥터)으로 봅니다. 한 규격에 실 있음·없음 행이 섞이면 후보가 둘인 것으로 보고 담당자가 고릅니다.
- 전선 규격은 같은 단위(sq, mm²)의 숫자로 비교합니다. AWG 표기는 단위 변환 기준을 확인하지 않아 읽지 않고 확인 대상으로 둡니다.
- 방수전은 빈 극 수 = 극수 − 회로 수로 계산하고, App Spec 에 방수전이 적힌 행이 없는 커넥터는 비방수로 보고 넣지 않습니다(설정에서 켤 때만).
- 전선 자체(길이 기준 자재)는 BOM 에 넣지 않았습니다. 길이 단위와 전선 품번 규칙이 제출 자료에 없습니다.
- 예시 데이터의 품번·코드·고객사는 모두 지어낸 것입니다.

## 수강생 자료가 있어야 하는 것 (기획서 10장)

1. 부품 매핑 마스터 샘플 — 열 이름, 고객사별 시트 여부, 한 품번에 제조사 품번·사내 코드가 여러 개인 경우
2. Application Spec 샘플 — 한 행 구성, 한 칸 여러 품번 여부, 전선 규격 단위, 방수전 포함 여부
3. 실제 도면 PDF 1~2건과 그 도면으로 작성한 BOM 1건 — 도구 결과와 대조할 정답, BOM 양식 열 순서
4. 터미널·실 수량 기준(극 수·회로 수·여유율), 방수전 기준, 후보가 여럿일 때 우선 기준
5. 도면·마스터를 외부 AI 에 올려도 되는지 — 2단계 도면 추출 방식 결정
